# Superstore Sales Data Analysis Using SQL

## 📌 Project Overview

This project analyzes the **Superstore Sales dataset** using **MySQL**. The goal of the project is to explore sales, profit, quantity, discount, categories, regions, states, cities, and product types using SQL queries.

The project contains **25 SQL questions and queries** covering basic to advanced SQL concepts.

## 🔍 Analysis Performed

The analysis includes:

- Displaying and filtering Superstore sales records
- Finding high-sales transactions
- Analyzing discounts and losses
- Sorting transactions by sales
- Calculating total and average sales, quantity, discount, and profit
- Creating profit status using `CASE`
- Comparing sales and profit by category
- Analyzing sales and profit by region
- Finding top product types based on sales
- Identifying cities and states based on sales performance
- Using subqueries for comparisons with average sales
- Using JOIN operations for sales and profit analysis
- Using set operators such as UNION and INTERSECT
- Applying window functions for ranking sales and profit

## 📁 Dataset

The project uses the **Superstore Sales dataset**, containing information related to sales transactions, including categories, product types, regions, cities, states, sales, quantity, discount, and profit.

## 🎯 Project Objective

The main objective of this project is to demonstrate practical SQL skills by analyzing a real-world sales dataset and extracting useful information using different SQL techniques.
